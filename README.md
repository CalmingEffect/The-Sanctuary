# The Sanctuary: The 60-Second Reset 🌊

An open-source, lightweight digital therapeutic sandbox designed to deliver immediate, low-barrier emotional regulation and acute distress mitigation. 

## 🧠 Clinical & Product Philosophy

In traditional telepsychiatry, the friction between a user experiencing acute overwhelm and accessing care is too high. **The Sanctuary** serves as a product archetype exploring **"micro-interventions"**—immediate, zero-friction tactile and auditory anchors that stabilize a user before routing them to formal clinical workflows or psychiatric support pathways.

### Key Architectural Features:
* **The 60-Second Reset:** A time-boxed, guided sensory calibration tool designed to interrupt acute sympathetic nervous system activation (the fight-or-flight response).
* **Multi-Modal Sensory Controls:** Real-time environmental sound toggle architecture to give users instant control over their acoustic atmosphere.
* **Dynamic Auditory Anchors:** Minimalist tactile interfaces ("Press if you feel overwhelmed") built to leverage grounding techniques.
* **Demographic Segmentation Toggle:** A structural pivot option ("Switch to Kids Room") demonstrating how core digital therapeutic pipelines can fork to serve pediatric vs. adult populations natively.

## 💻 Tech Stack & Deployment

* **Frontend:** Clean, semantic HTML5, localized CSS variables for soothing UI/UX palettes, and native JavaScript for zero-latency DOM manipulation.
* **Optimization:** Lightweight, dependency-free architecture to ensure sub-second rendering times on low-bandwidth mobile devices or integrated WebView wrappers.
* **Deployment:** Hosted securely via automated CI/CD deployment pipelines on GitHub Pages.
